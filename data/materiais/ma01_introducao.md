# Material de Apoio 01 - Introdução à Lógica de Programação

Fonte didática: Material de Apoio 01 da disciplina Algoritmos e Programação I.

O objetivo inicial é transformar um problema em uma sequência definida de passos
que um computador possa executar. Lógica é a organização do pensamento de forma
coerente para chegar a uma conclusão ou resolver um problema.

Programar não significa apenas decorar comandos. Antes da escrita do código, é
necessário compreender o problema, identificar as informações disponíveis,
planejar os passos e organizar a solução de forma lógica.

# Problema, análise, planejamento, algoritmo e programa

O processo começa pela identificação do problema. Em seguida, analisam-se as
informações necessárias e planejam-se os passos da solução. Esses passos são
organizados em um algoritmo. Por fim, o algoritmo é transformado em instruções
que o computador pode executar, formando o programa.

# Formas de representar um algoritmo

Um algoritmo pode ser apresentado por descrição narrativa, fluxograma ou
pseudocódigo. A descrição narrativa usa frases em linguagem comum. O fluxograma
representa graficamente as etapas e a direção do fluxo. O pseudocódigo se
aproxima de uma linguagem de programação, mas utiliza comandos simples.

Para calcular a área de um retângulo, uma solução narrativa pode: obter a base,
obter a altura, multiplicar base por altura e informar a área. Em pseudocódigo:

```text
Inicio
    Leia base
    Leia altura
    area <- base * altura
    Escreva area
Fim
```

# Decomposição de problemas

Problemas complexos podem ser divididos em partes menores. Para determinar a
situação de um estudante, por exemplo, pode-se: obter as notas, calcular a média,
verificar o critério de aprovação e informar o resultado. Resolver pequenas
partes separadamente facilita a compreensão e a implementação.
